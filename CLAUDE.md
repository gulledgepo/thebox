# Project Instructions

## Context Reference
Read `.claude/PROJECT_CONTEXT.md` at the start of any session for full project context (game mechanics, file map, design philosophy, z-index stack, etc.).

## Keeping Context Updated
After implementing a significant feature, new component, or meaningful change to game mechanics/balance, update `.claude/PROJECT_CONTEXT.md` to reflect the changes. This includes:
- New or removed components/files
- New stats, resources, or game systems
- Changed formulas, thresholds, or tuning values
- New UI elements or z-index changes
- Design decisions or philosophy shifts
